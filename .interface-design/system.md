# Woodventure — visual direction

Intent: a quiet browser game about doing physical work, taking long roads, noticing unmarked places. The world owns the screen. A tool is a tool, not a dashboard.

Domain: pine resin, survey stakes, logging roads, sawdust, rope, truck beds, corrugated roofs.
Color world: deep fir green, faded pickup teal, straw gold, wet slate, pale birch bark, copper evening light.
Signature: a continuous forest scene with overlapping individually shaded trees, long shadows, moving water and tiny workshop lights. Small stamped type, brass tool selectors, and a folded paper map extend the same world.
Defaults to avoid: quest panels, neon rarity indicators, permanent minimap. Use a field guide opened on demand, local context prompts, and no tracked objectives.

UI hierarchy: the canvas dominates; money/time occupy opposing corners; tool names live along the bottom. Overlay dialogs use native dialog for focus and keyboard behavior. Palette: --pine, --paper, --brass, --muted. Surfaces use one translucent pine family. Body 16px, captions 12–14px, title serif 80px, controls 44px minimum. Four-pixel spacing base; quiet fading, reduced-motion honored.

Version 0.3: orthographic Three.js volumes for physical objects, warm neutral daylight, faceted forest silhouettes, shared geometry. Keep painted terrain, parchment map and HTML interface. All scenery inscriptions are extruded DM Sans meshes fixed to physical surfaces. Use pale cream on dark timber and muted deep green on light price boards. Prices sit on angled metal plates attached to display tables; no billboard labels. No floating store, entrance or exit labels. The counter offers a small floor-aligned landing highlight only while a held product is close enough to place.

Version 0.4: terrain heights come from the same sampled triangle surface as traversal. Rounded ramps, rocky escarpments, muted biome color gradients and mixed forest borders. Dirt tracks have grain, wheel wear and soft edges. Atlas: parchment field notebook, understated relief, cursor-centered zoom, pan, optional map layers and player annotations. Known infrastructure comes from the world registry; hidden discoveries stay absent until visited. No permanent minimap or floating route arrows.
